# มะลิ (Mali) — ต้นแบบแอปโซเชียล

ต้นแบบเว็บแอปแบบ mobile-first ที่รวม **การแชร์รูปและวิดีโอ** (ฟีด สตอรี่ Reels สำรวจ โปรไฟล์) เข้ากับ **แชต** (แชตส่วนตัวและกลุ่ม, ช่องบรอดแคสต์, บัญชีทางการ, ทางลัดเพื่อน/กลุ่ม/บริการ) รองรับหลายภาษา เลือกฟอนต์ได้ และมีตัวกรองภาพ 18+ ในเครื่อง
ชื่อ โลโก้ดอกมะลิ 5 กลีบ คาแรกเตอร์ผู้ช่วย "น้องตูม" ภาพประกอบ ไอคอน และสติกเกอร์ ออกแบบขึ้นใหม่ทั้งหมด ไม่ได้ใช้ทรัพย์สินของแบรนด์อื่น

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้งอะไร เป็น HTML/CSS/JavaScript ล้วน ไม่มีขั้นตอน build

**แบบแนะนำ (ฟีเจอร์ความปลอดภัยและกล้องทำงานครบ):**

```bash
cd mali-social
python3 -m http.server 5173
```

แล้วเปิด <http://localhost:5173> บนเบราว์เซอร์ (ย่อหน้าต่างให้แคบหรือเปิดโหมดมือถือใน DevTools เพื่อดูแบบมือถือ)

**แบบเร็ว:** ดับเบิลคลิก `index.html` ได้เลย แต่ Web Crypto (2FA, แชตลับ, แฮชรหัสผ่าน) และกล้องอาจถูกบางเบราว์เซอร์ปิดเมื่อเปิดผ่าน `file://`

ทดลองบนมือถือจริง: รันเซิร์ฟเวอร์ด้านบน แล้วเปิด `http://<IP ของคอมพิวเตอร์>:5173` จากมือถือในวง Wi‑Fi เดียวกัน (กล้องต้องใช้ https หรือ localhost)

รีเซ็ตข้อมูลตัวอย่าง: โปรไฟล์ > ≡ > รีเซ็ตข้อมูลตัวอย่าง

## โครงสร้างโค้ด

```
mali-social/
├── index.html                  โครงหน้า + โหลดสคริปต์ตามลำดับ (ไม่ใช้ ES module เพื่อให้เปิดจาก file:// ได้)
├── css/app.css                 ระบบดีไซน์: โทเคนสี (สว่าง/มืด), สเกลระยะ 4px, คอมโพเนนต์, เลย์เอาต์มือถือ/แท็บเล็ต/เดสก์ท็อป
└── js/
    ├── core/
    │   ├── util.js             ตัวช่วยทั่วไป, ฟอร์แมตเวลาแบบไทย, ที่เก็บสถานะ (localStorage)
    │   ├── icons.js            ไอคอนเส้นที่วาดเอง
    │   ├── art.js              ภาพประกอบ SVG แบบ seed, อวาตาร์, โลโก้, น้องตูม, สติกเกอร์, ฟิลเตอร์
    │   ├── ui.js               แท็บ, สแตกหน้า + ปุ่มย้อนกลับ, ชีต, เมนู, toast, แถวตั้งค่า, event delegation (data-act)
    │   ├── security.js         TOTP, PBKDF2, E2EE, ตรวจลิงก์, rate limit, ลบ EXIF, คำที่ซ่อน, สรุปแชต
    │   ├── adult-filter.js     ตัวกรองภาพ 18+ (NSFWJS ในเครื่อง + ฮิวริสติกสำรอง)
    │   ├── appearance.js       ฟอนต์ ขนาดตัวอักษร สีวงสตอรี่
    │   └── i18n.js             ระบบภาษา (แปลระดับ DOM + Translator API ของเบราว์เซอร์)
    ├── data/seed.js            ข้อมูลตัวอย่างภาษาไทย (ผู้ใช้ โพสต์ สตอรี่ Reels แชต การแจ้งเตือน)
    ├── data/i18n-en.js         พจนานุกรมภาษาอังกฤษของ UI
    ├── screens/
    │   ├── home.js             หน้าหลัก: สตอรี่ ทางลัด ฟีด การ์ดโพสต์ ความคิดเห็น แชร์ อัลกอริทึมของคุณ
    │   ├── stories.js          ตัวดูสตอรี่ (24 ชม., Add Yours, ภาพเบลอขอดู, ไฮไลต์)
    │   ├── reels.js            Reels แนวตั้ง + วิดีโอยาวแนวนอน
    │   ├── explore.js          สำรวจ/ค้นหา + การแจ้งเตือน
    │   ├── profile.js          โปรไฟล์ ลากจัดเรียงตาราง โน้ต แก้ไขโปรไฟล์ รายชื่อคน
    │   ├── chat.js             แชต Instants แชตลับ สรุปกลุ่ม โทร แผนที่เพื่อน
    │   ├── hub.js              ทางลัด: เพื่อน กลุ่ม บริการ บัญชีทางการ
    │   ├── create.js           ปุ่ม + ตัวแก้ไขภาพ/วิดีโอ ไลฟ์
    │   ├── settings.js         เมนู ≡ ความเป็นส่วนตัว การโต้ตอบ แดชบอร์ดมืออาชีพ บัญชีวัยรุ่น
    │   └── security-center.js  ศูนย์ความปลอดภัย 2FA อุปกรณ์ อีเมลจากแอป กู้คืนบัญชี หน้าเข้าสู่ระบบ
    └── app.js                  จุดเริ่มต้น
```

แนวคิดหลัก: ทุกหน้าคือฟังก์ชัน `render()` ที่คืน HTML จากสถานะ `M.st` ปุ่มทุกปุ่มใช้ `data-act="ชื่อ"` แล้วเรียก `M.A.ชื่อ()` ผ่าน event delegation ตัวเดียว หลังแก้ข้อมูลให้เรียก `M.refresh()` (บันทึก + วาดใหม่)

## ความปลอดภัย: อะไรทำงานจริง อะไรจำลอง

**ทำงานจริงในเบราว์เซอร์**
- **2FA แบบ TOTP (RFC 6238)** ผ่านการทดสอบกับ test vector ของ RFC เพิ่มคีย์ลงแอปยืนยันตัวตนจริงได้ แล้วใช้รหัสนั้นเข้าสู่ระบบในต้นแบบ
- **แฮชรหัสผ่าน** PBKDF2‑SHA256 210,000 รอบ + salt สุ่ม ไม่เก็บรหัสผ่านตัวจริง
- **แชตลับ** ECDH P‑256 + AES‑GCM 256 บิต ข้อความถูกเก็บเป็น ciphertext (ดูได้ที่ ข้อมูลแชต > ดูข้อมูลที่เก็บในเครื่อง) พร้อมรหัสความปลอดภัย
- **ลบ EXIF/GPS** วาดรูปใหม่ลง canvas ก่อนบันทึก และแจ้งเมื่อพบพิกัดในไฟล์ต้นฉบับ
- **ตรวจลิงก์** รายการโดเมนหลอกลวงตัวอย่าง + ฮิวริสติก (IP, punycode, `@`, โดเมนเลียนแบบชื่อแอป, TLD เสี่ยง, http)
- **Rate limit ฝั่งไคลเอนต์** ข้อความ คอมเมนต์ การติดตาม การโพสต์ และการลองรหัส
- **คำที่ซ่อน** กรองความคิดเห็น
- **ตัวกรองภาพ 18+** โมเดล NSFWJS 4.2.1 (MobileNetV2) โหลดจาก jsDelivr แบบระบุเวอร์ชันและตรวจ SRI ทำงานในเครื่อง ไม่ส่งรูปออก ตรวจรูปโปรไฟล์ แบนเนอร์ (รวม GIF ใช้เฟรมแรก) โพสต์ และรูปในแชต: เนื้อหา 18+ ชัดเจนห้ามอัปโหลด, ภาพอ่อนไหวถูกเบลอพร้อมคำเตือน และใช้เป็นรูปโปรไฟล์/แบนเนอร์ไม่ได้, บัญชีวัยรุ่นใช้เกณฑ์เข้มงวด ถ้าโหลดโมเดลไม่ได้จะใช้ฮิวริสติกสีผิวซึ่งแม่นยำน้อยกว่ามาก
- **กู้คืนบัญชี** ตรวจรหัส 2FA หรือรหัสสำรองจริง แล้วบังคับตั้งรหัสผ่านใหม่และออกจากอุปกรณ์อื่น

**จำลอง** — AI ประเมินอายุ, SMS OTP, สรุปแชตด้วย AI (ใช้การดึงประโยคสำคัญแบบกฎ), พากย์เสียง AI, การโทร, ผู้ชมไลฟ์, การตอบแชตของเพื่อน, ยอดไลก์ใหม่, สถิติแดชบอร์ด

**ต้องทำที่เซิร์ฟเวอร์ในบริการจริง** — TLS/HSTS, เข้ารหัสข้อมูลที่จัดเก็บ + KMS, session token อายุสั้นผูกอุปกรณ์, device/IP risk scoring, rate limiting ต่อ IP/บัญชี/endpoint, ML ตรวจพฤติกรรมผิดปกติ, OAuth 2.0 + PKCE, audit log + least privilege, การสแกนลิงก์กับฐานข้อมูลภัยคุกคามแบบเรียลไทม์, SOC 24 ชม., Bug Bounty
(สรุปเดียวกันดูได้ในแอป: ≡ > ศูนย์ความปลอดภัย > ระบบหลังบ้านที่ต้องมีในบริการจริง)

## ข้อจำกัด

- ไม่มีระบบหลังบ้าน ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเบราว์เซอร์นี้เท่านั้น (ประมาณ 5 MB) อัปโหลดรูปจำนวนมากอาจบันทึกไม่ได้ ระบบจะแจ้งเตือน
- วิดีโอที่อัปโหลดเก็บในหน่วยความจำชั่วคราว รีเฟรชแล้วจะหายไป
- กุญแจแชตลับทั้งสองฝั่งอยู่ในเบราว์เซอร์เดียวกันเพื่อการสาธิต (ของจริงกุญแจส่วนตัวต้องไม่ออกจากเครื่องของแต่ละคน)
- เพลงเป็นชื่อสมมติ ไม่มีเสียง · คิวอาร์โค้ดเป็นภาพตกแต่ง สแกนไม่ได้
- โดเมนตัวอย่างใช้ `mali.example` (โดเมนสงวนสำหรับตัวอย่าง)
- ภาษาอื่นนอกจากไทย/อังกฤษ ต้องใช้เบราว์เซอร์ที่มี Translator API แบบในเครื่อง (Chrome รุ่นใหม่บนคอมพิวเตอร์) และอาจต้องดาวน์โหลดโมเดลภาษาครั้งแรก ถ้าไม่มีหรือใช้ไม่ได้ภายใน 8 วินาทีจะแสดงเป็นภาษาอังกฤษ คำแปลที่ได้เป็นการแปลด้วยเครื่อง ควรให้ผู้แปลตรวจก่อนใช้จริง
- การแปลทำที่ระดับ DOM ข้อความ UI ที่ประกอบกับชื่อคนอาจแปลไม่ครบ ข้อความของผู้ใช้ (โพสต์ แชต ความคิดเห็น ชื่อ Bio) แสดงตามภาษาที่เขียนเสมอ
- ตัวกรอง 18+ ต้องออนไลน์ในครั้งแรกเพื่อโหลดโมเดล (ประมาณ 6 MB ครั้งแรกใช้เวลาหลายวินาที) และผลอาจผิดพลาดได้ บริการจริงต้องตรวจซ้ำที่เซิร์ฟเวอร์และมีช่องทางอุทธรณ์
- ฟอนต์ Anuphan โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยของระบบแทน

## แนวทางดีไซน์

- โทนกระดาษอุ่น (`#f7f4ee`) + สีเน้นส้มอิฐ `#c4411a` เพียงสีเดียว ใช้กับปุ่มหลัก การเลือก ถูกใจ และตัวเลขสำคัญ (ตัวหนังสือขาวบนสีเน้นผ่านคอนทราสต์ 4.5:1)
- ไม่มี gradient ม่วง-ฟ้า, glow หรืออีโมจิใน UI (ใช้แนวทางจาก [unslop](https://github.com/heydamir/unslop) โดย Damir Sokolovsky, CC BY 4.0)
- ความโปร่งแสงแบบ Liquid Glass ใช้เฉพาะแถบบนและแถบนำทาง และปิดอัตโนมัติเมื่อผู้ใช้ตั้งค่า "ลดความโปร่งใส"
- รองรับธีมมืด, `prefers-reduced-motion`, focus ที่มองเห็นได้, และ `aria-label` บนปุ่มไอคอน

## การตรวจสอบที่ทำแล้ว

- `node --check` ทุกไฟล์ JavaScript ผ่าน
- REA (`analyze_javascript_application`): อ่าน JS 17 ไฟล์ แยกวิเคราะห์ไม่ผิดพลาดเลย การเข้าถึง localStorage มีเฉพาะใน `js/core/util.js` และโค้ดแอปไม่เรียก fetch/WebSocket หรือส่งข้อมูลออกนอกเครื่อง (เป็นการวิเคราะห์แบบ static ไม่ได้รันโค้ด)
- สคริปต์ตรวจว่า `data-act` ทั้ง 109 รายการ และหน้าทั้ง 43 หน้ามีโค้ดรับจริง
- เปิดทุกหน้าในเบราว์เซอร์แล้วไม่พบ error และทดสอบที่ความกว้าง 375 px และ 1280 px
